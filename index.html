Wi-Fi setup

  1. Power the rover and join its Wi-Fi network (or put both on the same router).
  2. Find the ESP32 IP in the serial monitor or router.
  3. Enter it above as http://IP, then Save and test.
  4. This site is HTTPS, so browsers block plain-HTTP rovers. See README: use a secure tunnel, or run this app locally over HTTP.
